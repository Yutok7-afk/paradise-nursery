# Paradise Nursery

## Project Name
Paradise Nursery — Online Houseplant Shopping Cart

## Description
Paradise Nursery is a React + Redux shopping cart application where users can
browse a wide variety of houseplants organized by category, add them to a
shopping cart, and manage quantities on the cart page.

## Features
- Beautiful landing page with a "Get Started" button
- Product listing grouped into 3 categories
- Add to Cart with button disabling
- Dynamic cart icon count in the navbar
- Cart page with quantity increase/decrease, delete, and total price
- Checkout and Continue Shopping buttons

## Tech Stack
- React
- Redux Toolkit
- React Router
- CSS
